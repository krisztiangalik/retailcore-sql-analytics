# User Story

As a business stakeholder,
I want to receive a reliable daily sales report for every store,
so that I can review the previous day's sales performance and identify missing or unreliable data before making decisions.

## Business value

The report helps management:
- compare store performance
- identify missing daily data
- detect duplicate sales
- detect sales without sale items
- avoid using incomplete or unreliable data for decision-making

## Definition of Done

- Source-to-target mapping is documented.
- Data quality rules are defined.
- SQL implementation is completed.
- All active stores are included in the output.
- Data quality flags are generated.
- availability_status is calculated correctly.
- Query results have been validated against the source data.
